# 타이포그래피 가이드

토큰 정의는 `globals.css`의 `@theme` 안 `--text-*`. 값 하나 수정하면 전체 반영됨.
`text-xs`·`text-sm`·`text-lg`·`text-[13px]` 같은 Tailwind 기본/임의 크기는 쓰지 않음.

## 크기 토큰

| 클래스             | 크기 / 행간          | 굵기 | 용도                                                       |
| ------------------ | -------------------- | ---- | ---------------------------------------------------------- |
| `text-display`     | 30→36px(유동) / 1.2  | 700  | 페이지 히어로 h1, 길드명 같은 페이지 대표 이름             |
| `text-title`       | 20 / 28              | 700  | 페이지 제목, 빈 상태·오류 화면 제목, 검색 결과 헤더        |
| `text-heading`     | 18 / 26              | 700  | 페이지 안 섹션 제목(h2), 다이얼로그 본문 대제목            |
| `text-subheading`  | 16 / 24              | 700  | 카드·다이얼로그·시트 제목(`CardTitle` 등 기본값)           |
| `text-body-lg`     | 16 / 24              | -    | 목록의 대표 이름(아이템명·캐릭터명), 내비게이션, 히어로 문구 |
| `text-body`        | 14 / 20              | -    | 기본 본문, 버튼·입력·표                                    |
| `text-body-sm`     | 13 / 20              | -    | 촘촘한 목록·칩(길드 순위표, 세트 칩)                       |
| `text-caption`     | 12 / 16              | -    | 보조 설명, 날짜·메타 정보, 배지, 툴팁                      |
| `text-micro`       | 10 / 14              | 600  | 아이콘 위 배지, 빈 슬롯 라벨                               |

- 제목 토큰(display~subheading)과 micro는 굵기·자간 포함 → `font-bold` 추가 불필요
- 본문 토큰(body-lg~caption)은 굵기 미포함 → 부모 굵기 상속, 필요하면 `font-*` 지정
- `font-*`, `leading-*`, `tracking-*`를 같이 쓰면 토큰 값보다 우선함
- 반응형 크기 변경은 한 단계까지만 허용(`text-caption md:text-body`, `text-body md:text-body-lg`)

## 굵기 규칙

| 굵기            | 쓰는 곳                                                              |
| --------------- | -------------------------------------------------------------------- |
| 700 `bold`      | 제목 토큰에만 포함. 클래스로 직접 쓰지 않음                          |
| 600 `semibold`  | 이름·수치 강조(캐릭터명, 길드명, 순위, 합계, 결과값), 카드 안 소제목 |
| 500 `medium`    | 라벨·컨트롤(버튼, 탭, 메뉴, 폼 라벨, 정보 행 라벨), 빈 상태 안내     |
| 400 `normal`    | 본문, 설명, 메타 정보                                                |

- 카드 안 소제목(카드 제목 아래 단락 제목)은 `text-body font-semibold`
- 수치를 나란히 비교하는 곳은 `tabular-nums` 추가

## 예외

- `HeaderLogo`: 브랜드 표기라 고정 크기 유지
- `PhotoCard`, `SpecCardContent`: 이미지로 내보내는 고정 레이아웃
- `ItemIconBase` 배지: 아이콘 크기에 맞춘 9px·`font-bold`
- 아이템 상세 다이얼로그는 크기 토큰만 사용, 색은 `game-*` 팔레트
